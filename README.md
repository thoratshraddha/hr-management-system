# Human Resource Management System

A desktop-based HR management application with complete employee management features built using Java and MySQL.

## Tech Stack
- **Language:** Core Java
- **Database:** MySQL
- **IDE:** NetBeans
- **Reporting:** Jaspersoft

## Features
- 👨‍💼 Employee records management
- ➕ CRUD operations (Add, Update, Delete, View)
- 🔐 Secure login system
- 📊 Reports generation using Jaspersoft
- 🖥️ Desktop GUI application
- 📁 Department and role management



## How to Run
1. Clone the repository
2. Open project in **NetBeans IDE**
3. Setup MySQL database
4. Configure DB connection in the project
5. Run the project
